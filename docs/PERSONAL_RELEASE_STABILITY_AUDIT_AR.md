# تدقيق نسخة Release الشخصية المستقرة

## ما أصلح في هذا الإصدار

يفتح الرابط العادي وAPK وضع ضيف محدوداً للأصدقاء مباشرة، من دون طلب تسجيل الموقع أو رمز دخول. لا يظهر في هذا الوضع قسم المطور أو الرسائل أو الموصلات أو المفاتيح. يبقى مسار المطور منفصلاً ومحمياً.

تم استبدال رجوع المشاركة الذي كان يفتح رابط واتساب في المتصفح بجسر Android أصلي. يحفظ التطبيق صورة الإعلان داخل مستندات التطبيق ثم يطلب من لوحة مشاركة Android اختيار واتساب أو التطبيق المناسب. لا يستدعي هذا المسار رابط `wa.me` من داخل APK.

## إثبات بنية الحزمة

| بند | النتيجة |
|---|---|
| إطار التطبيق | Capacitor فقط |
| معرّف الحزمة | `com.marwan.ghorfatalmalabes` |
| الإصدار | `1.0.0` — `versionCode 2` |
| واجهة التطبيق | `assets/public/index.html` وملفات `dist` موجودة داخل APK |
| نموذج الإزالة وWASM والشعار | موجودة داخل APK |
| `server.url` في Capacitor | غير موجود |
| TWA / Bubblewrap / Custom Tabs | لا توجد مراجع داخل الأرشيف |
| توقيع APK | v1 وv2 ناجحان؛ v3 وv4 غير مفعّلين |
| سلامة الأرشيف | ناجحة |

## الفحوص البرمجية

نجح اختبار مسار الضيف الذي يثبت عدم استدعاء فحص الدخول من الرابط العادي. ونجح اختبار جسر مشاركة Android الذي يثبت كتابة ملف PNG محلياً ثم استدعاء لوحة المشاركة الأصلية. كما نجحت حزمة الجودة الكاملة، فحص الهاتف، البناء، وميزانية الأداء؛ ولم تتجاوز CSS `129.9KiB` من حد `130KiB`.

## الحد الواقعي

لا يمكن اعتماد سلوك هاتف صديق أو اختلافات المعرض وواتساب من دون تجربة فعلية. يلزم تثبيت APK على هاتفين Android: فتح التطبيق بلا حساب، رفع صورة، ثم إرسال إعلان واحد من لوحة مشاركة Android. هذا قبول يدوي متبقٍ ولا يدّعي هذا التقرير إتمامه مسبقاً.
