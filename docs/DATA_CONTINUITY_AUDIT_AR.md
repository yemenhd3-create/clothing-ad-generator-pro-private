# تدقيق استمرارية البيانات والخدمة

## النتائج الأولية

تُحفظ هوية المركز وذاكرة المساعد محلياً في متصفح المستخدم. هذه الآلية تعمل بلا إنترنت، لكنها لا تنتقل تلقائياً إلى هاتف آخر ولا تنجو من مسح بيانات المتصفح ما لم يُنشئ المستخدم نسخة تصدير.

النسخ المحلي الحالي ينتج ملف JSON منظماً يضم ملف المركز وذاكرة المساعد وإعدادات القالب. لا يتضمن مفاتيح API ولا ملفات الصور ولا نموذج إزالة الخلفية؛ وهذا فصل مقصود حتى لا تنتقل الأسرار إلى ملف مشاركة أو Google Drive.

## قرار الاستمرارية

سيكون أساس الاستمرارية هو: حفظ محلي يعمل دون إنترنت، وتصدير واستيراد ملف إعدادات آمن، ورجوع محلي للنص والمعالجة عند تعذر الشبكة أو مزود خارجي. لا يعتمد التطبيق على Google Drive أو أي مزود واحد لتشغيله الأساسي.

مفاتيح API تظل ضمن تخزين الخادم المشفر ولا تدخل في النسخ المصدرة. يمكن لاحقاً إضافة Google Drive كوجهة اختيارية لملف النسخة الآمن فقط بعد اتصال Google صريح، لكنه ليس مصدراً وحيداً ولا موقعاً للمفاتيح.

## تدقيق تسجيل المستخدمين

يدعم التطبيق مسارين مستقلين للوصول: حساب OAuth المعتاد، أو رمز دخول صادر من المطور ينشئ جلسة محددة المدة. عند تعطل إدخال الرمز، تبقى واجهة التسجيل تعرض مسار الحساب المعتاد ولا تكشف بيانات حساسة. كما أن رمز الدخول يحترم وقت الانتهاء والاستخدامات المسموح بها ويصدر جلسة تنتهي بالمدة ذاتها.

التحسين المطلوب في المرحلة التالية هو جعل رسالة فشل الخدمة أو انتهاء الجلسة قابلة للتصرف: إعادة المحاولة، الرجوع إلى الرمز أو الحساب المعتاد، وتوضيح حالات المتصفح الذي يمنع ملفات الارتباط. لا ينبغي إنشاء مسار OAuth ثانٍ أو تغيير حماية nonce الحالية.
