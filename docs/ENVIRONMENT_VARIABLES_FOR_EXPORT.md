# متغيرات الإعداد للتصدير

لا تتضمن حزمة التصدير ملف `.env` أو قيماً حقيقية. عند تشغيل نسخة مستقلة، أنشئ ملف البيئة محلياً وأدخل القيم من لوحة الخدمة الخاصة بك فقط.

| المتغير | الغرض |
|---|---|
| `DATABASE_URL` | رابط قاعدة البيانات الاختياري |
| `JWT_SECRET` | توقيع جلسات الخادم |
| `VITE_APP_ID` | هوية تطبيق OAuth |
| `OAUTH_SERVER_URL` | خادم OAuth |
| `VITE_OAUTH_PORTAL_URL` | بوابة تسجيل الدخول |
| `OWNER_OPEN_ID` | هوية مالك المشروع |
| `BUILT_IN_FORGE_API_URL` | واجهة الخدمات المدمجة |
| `BUILT_IN_FORGE_API_KEY` | مفتاح خدمات الخادم المدمجة |
| `GEMINI_API_KEY` | مفتاح اختياري للنص المتصل |
| `VITE_APP_TITLE` | عنوان الواجهة |
| `VITE_APP_LOGO` | شعار الواجهة الاختياري |

> لا تضع مفاتيح API أو كلمات مرور أو بيانات جلسات في الأرشيف، أو في مستودع عام، أو في ملف النسخة الاحتياطية للمستخدم.
