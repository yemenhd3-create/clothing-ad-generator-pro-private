# حزمة دمج ميزات محرر الصور لمشروع مولد إعلانات الملابس

**المصدر الذي تم تحليله:** `BackgroundEraser-PhotoEditor_2.351.105.zip`  
**نوع المصدر:** APK Android مفكوك/مستخرج من تطبيق مترجم، وليس مستودعًا مفتوح المصدر.  
**الغرض:** تحديد الأفكار والأدوات المفيدة لمشروع الملابس وتحويلها إلى مواصفة تنفيذ آمنة.

> هذه الوثيقة لا تنسخ كود التطبيق الأصلي أو نماذجه أو أصوله. يجب تنفيذ الميزات من الصفر باستخدام أدوات المشروع الحالية ومكتبات ذات تراخيص مناسبة.

---

## 1. النتيجة العامة للتحليل

الملف هو حزمة تطبيق Android باسم ظاهر قريب من:

- **Background Eraser**
- **Background Eraser - Photo Editor**
- اسم الحزمة الظاهر في السلاسل: `photoeditor.cutout.backgrounderaser`
- إصدار ظاهر داخل الكود: `BGEraser/105000`

توجد داخله وظيفتان واضحتان:

1. **إزالة الخلفية والقص الذكي**.
2. **تحرير الصورة بعد القص**.

ومن الأدلة الموجودة داخل الحزمة:

- `assets/image_matting.model` — نموذج محلي مرتبط بالـ matting/إزالة الخلفية.
- `bgeraser/models/face_attr_v2.model` — نموذج/ملف متعلق بخصائص الوجه، وليس مطلوبًا لمشروع الملابس.
- أسماء واجهات مثل `Cutout`, `Eraser`, `Shadow`, `Sticker`, `Text`, `Layer`, `Gallery`.
- ملفات إرشاد Lottie لأدوات `auto`, `brush`, `eraser`, `lasso`, `magic`, `smooth`, `expand`, `enhance`.
- وجود سجلات `mUndoList` و`mRedoList` يدل على نظام تراجع وإعادة.
- وجود `image_matting.model` يدل على مسار معالجة محلي أو مضمّن، لكن لا يمكن الجزم من APK وحده بطريقة التشغيل التفصيلية أو الترخيص.

## 2. الميزات المهمة التي تستحق الظهور في مشروع الملابس

### أولوية P0 — دمج مباشر

هذه الميزات متوافقة مع مشروعك الحالي وخصوصية العمل دون إنترنت:

1. **إزالة خلفية تلقائية محسنة**
   - زر واحد باسم: `إزالة تلقائية`.
   - استخدام المسار المحلي الحالي ONNX أولًا.
   - إظهار معاينة قبل/بعد.
   - الاحتفاظ بإمكانية الرجوع للصورة الأصلية.

2. **فرشاة استعادة/إزالة يدوية**
   - `فرشاة إضافة`: استعادة أجزاء من الملابس حُذفت خطأ.
   - `ممحاة`: حذف أجزاء زائدة من القناع.
   - حجم الفرشاة: صغير، متوسط، كبير.
   - كثافة/نعومة الحافة.
   - تكبير وتحريك الصورة أثناء التصحيح.

3. **أداة اللمس الذكي Magic/Auto Select**
   - الضغط على منطقة من الملابس لتحديد المنطقة المتصلة أو المتشابهة.
   - تستخدم القناع المحلي الموجود بدل إرسال الصورة للخارج.
   - لا تطبق التغيير نهائيًا قبل زر «اعتماد».

4. **تنعيم الحواف Edge Smooth**
   - إزالة التعرجات الناتجة عن القناع.
   - Feather/تنعيم خفيف.
   - Contract/Expand للقناع ببكسلات قليلة.
   - Decontamination اختياري لتقليل لون الخلفية حول الملابس.

5. **ظل المنتج**
   - ظل أرضي اصطناعي خلف القطعة.
   - التحكم في: الشفافية، النعومة، الاتجاه، الإزاحة، اللون.
   - لا يُدمج في الصورة الأصلية إلا عند التصدير.

6. **نظام Undo/Redo حقيقي**
   - سجل حالات التحرير بدل تعديل الصورة الأصلية مباشرة.
   - يدعم إزالة الخلفية، الفرشاة، الممحاة، التنعيم، الظل، التحجيم.
   - زر تراجع وإعادة واضحان.

### أولوية P1 — قيمة عالية للإعلانات

7. **قص يدوي/حر مع نسب جاهزة**
   - 1:1، 4:5، 9:16، 16:9، 3:4.
   - قص مخصص.
   - قفل النسبة.
   - شبكة محاذاة.

8. **توسعة مساحة التصميم Expand Canvas**
   - توسيع اللوحة حول المنتج دون تغيير أبعاد المنتج.
   - خلفية لون واحد أو شفافة أو من ألوان الهوية.
   - يجب أن تعمل كمساحة تصميم، لا كتوليد صورة خارجي.

9. **تحسين بسيط للصورة Enhance**
   - سطوع، تباين، تشبع، حدّة، ظلال، إضاءة.
   - Presets: `طبيعي`, `منتج أبيض`, `منتج داكن`, `استوديو`.
   - معالجة محلية قابلة للإلغاء.

10. **طبقات Layers**
    - طبقة الملابس.
    - طبقة الخلفية.
    - طبقة الظل.
    - طبقة الشعار.
    - طبقة النص/السعر.
    - إعادة ترتيب الطبقات وقفلها وإخفاؤها.

11. **نصوص وملصقات**
    - نص قابل للتحرير.
    - خطوط عربية محلية.
    - حجم، لون، وزن، محاذاة، ظل، خلفية النص.
    - ملصقات بسيطة مثل: `جديد`, `خصم`, `متوفر الآن`.
    - يجب ألا تُضاف أي معلومة تلقائيًا إذا لم يدخلها المستخدم.

12. **اختيار عدة صور من المعرض**
    - تحديد حتى 10 صور كما هو حد الدفعة الحالي.
    - معاينة مصغرات.
    - تطبيق قالب/إعداد مشترك.
    - تعديل كل صورة منفردة.
    - إلغاء أو إعادة محاولة صورة واحدة دون إعادة الدفعة كلها.

### أولوية P2 — تحسين تجربة الاستخدام

13. **إرشاد تفاعلي لأول استخدام**
    - جولة قصيرة لأزرار: تلقائي، فرشاة، ممحاة، ظل، حفظ.
    - يمكن تخطيها.
    - تخزين حالة الإكمال محليًا.

14. **مقارنة قبل/بعد**
    - منزلق Before/After.
    - خيار عرض الخلفية الشطرنجية للشفافية.
    - لا يغير الملف النهائي.

15. **تصدير ومشاركة محسنة**
    - PNG شفاف.
    - JPG بخلفية اختيارية.
    - WebP عند دعم الجهاز.
    - مشاركة مباشرة.
    - اسم ملف منظم مثل: `اسم-المنتج-إعلان-2026-10-13.png`.

16. **حفظ مشروع قابل لإعادة التحرير**
    - حفظ JSON محليًا يحتوي على الإعدادات والمواقع والطبقات، لا الصورة فقط.
    - مثال: `.wardrobe-project.json`.
    - الصور تبقى محلية، مع خيار حذف المشروع.

## 3. ميزات لا أنصح بنسخها إلى مشروعك

### الإعلانات والتحليلات

الحزمة تحتوي على مؤشرات لمكتبات:

- Firebase Analytics.
- Google Mobile Ads/AdMob.
- Pangle/شبكات إعلانات.
- Crash/measurement services.

لا تضفها تلقائيًا. مشروع الملابس يجب أن يبقى سريعًا وخصوصيًا، ولا يحتاج إلى إعلانات داخل محرر إعلان تجاري.

### الاشتراكات والفوترة

توجد مؤشرات على Google Play Billing ورسائل اشتراك وتجربة مجانية. لا تُدمج إلا إذا قررت لاحقًا نموذجًا تجاريًا واضحًا، مع شاشة أسعار وسياسة خصوصية واستعادة مشتريات.

### نموذج الوجه

`bgeraser/models/face_attr_v2.model` لا يخدم هدف صور الملابس مباشرة. لا تستخدمه لتحليل العمر أو الجنس أو السمات الشخصية.

### أصول التطبيق الأصلية

ملفات Lottie والصور والخطوط الموجودة داخل APK قد تكون مملوكة لصاحب التطبيق أو مرخصة بشروط غير معروفة. لا تنسخها إلى مشروعك. نفذ رسوماتك أو استخدم أصولًا مرخصة.

### المرحلة D — التراجع وإعادة التنفيذ

**الملف المقترح:**

```text

```

```ts
export class HistoryStack<T> {
  private undoStack: T[] = [];
  private redoStack: T[] = [];

  push(state: T) {
    this.undoStack.push(state);
    this.redoStack = [];
  }

  undo(current: T): T | null {
    const previous = this.undoStack.pop();
    if (!previous) return null;
    this.redoStack.push(current);
    return previous;
  }

  redo(current: T): T | null {
    const next = this.redoStack.pop();
    if (!next) return null;
    this.undoStack.push(current);
    return next;
  }

  clear() {
    this.undoStack = [];
    this.redoStack = [];
  }
}
```

لا تحفظ صورًا كاملة في كل خطوة؛ احفظ العمليات والإعدادات أو نسخة مضغوطة محدودة لتجنب استهلاك الذاكرة.

- تحسين نص تسويقي عبر مزود متصل.

لا ترسل الصورة تلقائيًا عند تشغيل ميزة محلية.

## 8. معايير القبول قبل اعتماد الدمج

- لا تفقد الصورة الأصلية عند أي عملية.
- زر التراجع يعيد الحالة السابقة بدقة.
- زر الإعادة يعمل بعد التراجع.
- الفرشاة لا تعدل خارج حدود الصورة.
- التنعيم لا يحذف تفاصيل الملابس المهمة.
- الظل لا يغطي المنتج ولا النص.
- تغيير الحجم لا يعيد تشغيل النموذج المحلي.
- لا تُرفع الصورة في الوضع المحلي.
- التصدير PNG يحافظ على الشفافية.
- التصدير JPG يعرض خلفية اختيارية صحيحة.
- النتيجة تمر عبر `Quality Gate` و`Pixel Truth Gate`.
- الذاكرة لا تنمو بلا حد أثناء 10 صور متتالية.
- إلغاء الدفعة يوقف الصور التالية ويحفظ النتائج المكتملة.
- Android وPWA يعرضان نفس النتيجة الأساسية.

## 9. فحص قانوني وتقني قبل استخدام أي نموذج أو أصل

1. لا تدمج `image_matting.model` مباشرة من APK قبل معرفة مالكه وترخيصه.
2. لا تنسخ ملفات `.dex` أو كودًا مفكوكًا أو ملفات Lottie الأصلية.
3. لا تنسخ خطوطًا أو صورًا أو أيقونات من التطبيق دون ترخيص.
4. استخدم نموذجًا مفتوحًا بترخيص مناسب، مثل نموذج ONNX موثق الترخيص، بعد فحص شروط الاستخدام التجاري.
5. سجّل مصدر كل مكتبة ونموذج في ملف `THIRD_PARTY_NOTICES.md`.
6. لا تضف Firebase أو الإعلانات لمجرد أنها موجودة في التطبيق المصدر.
7. اختبر الذاكرة والحرارة على هاتف Android حقيقي قبل اعتماد نموذج أثقل.

## 10. الخلاصة التنفيذية

أفضل دمج لمشروع الملابس ليس نسخ التطبيق كاملًا، بل إضافة هذه الحزمة بالترتيب:

```text
1. فرشاة إضافة + ممحاة للقناع
2. تنعيم/توسيع/تقليص الحواف
3. Undo/Redo
4. ظل المنتج
5. مقارنة قبل/بعد
6. تحسينات الصورة
7. طبقات وشعارات ونصوص
8. قص وتوسعة ومساحات جاهزة
9. حفظ مشروع قابل لإعادة التحرير
```

هذه الإضافات تجعل مشروع الملابس أقرب إلى محرر احترافي، مع المحافظة على ميزته الأساسية: **العمل دون إنترنت والخصوصية وعدم الاعتماد على مفتاح خارجي**.

**حالة الوثيقة:** جاهزة كمرجع دمج وتنفيذ، وليست تعديلًا تلقائيًا للكود.
