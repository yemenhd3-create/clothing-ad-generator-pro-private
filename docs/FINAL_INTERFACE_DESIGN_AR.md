# عقد تصميم التسليم النهائي — غرفة الملابس

## الهدف

تبقى شاشة العمل الأساسية ثابتة: **صورة الملابس في الوسط، أدوات قصيرة أسفلها، وإعدادات عامة في أعلى الشاشة**. لا يحتاج المستخدم إلى قراءة طويلة أو النزول صعوداً لمشاهدة النتيجة.

## قواعد الواجهة

| القرار | التطبيق |
|---|---|
| أولوية واحدة | رفع الصورة ثم إنشاء صورة الاستديو؛ تظهر الخيارات الأخرى فقط بعد وجود صورة. |
| رموز واضحة | لكل رمز لون هادئ وحد خفيف واسم قصير تحت الرمز؛ لا رموز بلا تسمية. |
| أدوات قصيرة | تنفتح نافذة عائمة فوق القالب وتغلق بالنقر خارجه؛ لا صفحة إعدادات طويلة أثناء التعديل. |
| رجوع آمن | يظهر زر «صورة جديدة» داخل الاستديو ويعيد إلى اختيار الصورة فقط، ولا يمسح الإعدادات. |
| إعدادات عامة | زر الإعدادات في أعلى الشاشة، أما أدوات الصورة فهي في الشريط السفلي وحده. |
| تنقل بسيط | الشريط الرئيسي يعرض «إنشاء» و«إعدادات» للمستخدم، ومدخل المطور المحمي يظهر في الإعدادات فقط. |
| قوالب اختيارية | شريط أفقي قصير من عينات ملونة؛ لا اختيار تلقائي للفئة ولا تغيير للصورة نفسها. |
| حقيقة المنتج | 2D يرسم القطعة كما هي؛ 2.5D يضيف ظلاً أو منصة خلفها فقط ولا يختلق زاوية أو نسيجاً. |

## ترتيب أدوات الاستديو

1. تعديل الصورة
2. القوالب
3. الخلفية
4. العرض 2D / 2.5D
5. الحجم
6. المقاس
7. العنوان
8. النص التسويقي

لا تظهر خيارات تنقيح أو ألوان أو نصوص طويلة إلا عند اختيار أداتها. وتحافظ الواجهة على تباين واضح، مساحة لمس لا تقل عن 44 بكسل، وأسماء نصية لكل عنصر ليتعامل معها المستخدم الذي لا يقرأ بسهولة أو الذي يفضل الإشارات المرئية.
