# تقرير الأمان والخصوصية

## نتائج فحص المصدر وAPK

| Finding | Severity | Location | Resolution |
|---|---|---|---|
| أسرار إنتاجية أو مفاتيح API ثابتة في المصدر | لا يوجد نمط مكشوف في الفحص النصي | المصدر الملتزم | المتغيرات السرية خارج Git |
| private key أو شهادة توقيع داخل المستودع | لا يوجد | Git tree و`.gitignore` | keystore خارج المصدر |
| `server.url` أو TWA/Custom Tab في إعداد Capacitor | لا يوجد | `capacitor.config.json` وAPK | الواجهة محلية مضمّنة |
| HTTP غير المشفر ضمن إعداد Android | لا يوجد في Manifest | `android/app/src/main/AndroidManifest.xml` | الاتصال المعلن هو INTERNET فقط؛ تُراجع روابط الخدمات المتصلة عند تفعيلها |
| قالب اختبار بحساب أو كلمة مرور حقيقية | لا يوجد دليل | الاختبارات والمصدر | بيانات الاختبار لا تحتوي أسراراً إنتاجية |
| مسار مطور مخفي أو تعطيل عن بعد | لا يوجد دليل في الفحص الحالي | `client/`, `server/`, APK | أدوات المطور خلف مصادقة، وليست kill switch |

الفحص ليس بديلاً عن مراجعة يدوية مستقلة أو فحص secrets مخصص قبل كل إصدار. لا تضع أسراراً في تقرير أو Issue أو Commit.

## تدفق البيانات

| المرحلة | البيانات | المكان | هل تغادر الجهاز؟ |
|---|---|---|---|
| Input | صورة القطعة وإعدادات القالب | ذاكرة التطبيق | لا |
| Processing | مصفوفة الصورة ونتيجة U2Net وقناع الشفافية | ذاكرة التطبيق/Cache محلي | لا |
| Storage | PNG الناتج والمسودة المحلية | جهاز المستخدم | لا، إلا إذا شاركها المستخدم |
| Output | تنزيل أو Android Share Sheet | ملف محلي أو تطبيق اختاره المستخدم | عند المشاركة فقط إلى التطبيق المختار |
| Optional online AI | نص أو بيانات يرسلها المسار المتصل | مزود الخدمة المحدد | نعم عند اختيار المسار المتصل |
| Optional server auth | جلسة OAuth وبيانات الخادم | خادم Manus/الخدمة المهيأة | نعم عند استخدام الحساب أو أدوات المطور |

## القيود والميزات المخفية

لم يظهر في الملفات التي فُحصت منطق عام يفرض User Limit أو Device Limit أو Time Bomb أو Remote Disable أو IP/دولة. القيود التقنية الموثقة هي حد Android الأدنى `minSdk 23`، وذاكرة الهاتف المطلوبة لتشغيل النموذج، وحدود WebView/Canvas، وحدود مزود AI عند استخدامه. هذه ليست قيوداً تجارية مقصودة ولا تُزال دون كسر المنصة.

## حسابات وخدمات خارجية

المسار المحلي لا يحتاج قاعدة بيانات أو OAuth أو Storage سحابية. موقع الويب المنشور وخدمات Manus وقاعدة البيانات المرتبطة ببيئة WebDev ليست بديلاً عن APK المستقل، ولا ينبغي نقل أسرارها إلى العميل. يجب على المالك نقل حساب GitHub، حساب النشر، قاعدة البيانات، التخزين، وحسابات مزودي AI إلى ملكيته قبل اعتبار بند الاستقلالية مغلقاً.
